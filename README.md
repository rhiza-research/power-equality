# power-equality

A repository of tools to analyze and visualize power quality data, focused on highlighting power quality issues in the global south.

## Setup

To run or contribute to the analysis in this repository, all you need is [uv](https://docs.astral.sh/uv/getting-started/installation/).

Once uv is installed, activate the environment for this project (dependencies are defined in [pyproject.toml](pyproject.toml)):

```bash
uv sync
```

You should then be able to call any of the functions in this repository.
